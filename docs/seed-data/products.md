# Product Seed Data

Phase 1 で開発ストア（sweet-atelier-demo）に登録する **架空のダミー商品データ**を記録するもの。

このドキュメントは:
- 商品データの定義書（管理画面入力時の参照元）
- 開発ストアをリセットした時の復元用 seed
- 後の Phase でデータ駆動の表示を実装する際の検証用データ

## 共通方針

- **すべて架空**：実在ブランド・店舗・商品名を流用しない
- **オリジナルコピー**：説明文はブランド方向性（季節と素材を映す、小さなケーキのアトリエ）に沿って書き下ろし
- **トーン**：ですます調 + 体言止めミックス、ハートフェルトで派手すぎない
- **画像**：ChatGPT で生成した 1024×1024 PNG を `docs/seed-data/products/` に保管（同階層）

## コレクション設計

| Handle | タイトル | 用途 |
|---|---|---|
| `signature` | 定番 | 通年販売の主力商品 |
| `seasonal` | 季節のケーキ | 春夏秋冬の限定品 |
| `gifts` | ギフト | 贈答用・焼き菓子・詰合せ |
| `baked-goods` | 焼き菓子 | クッキー・フィナンシェ等 |
| `anniversary` | アニバーサリー | 記念日・誕生日のホールケーキ |

商品ごとに 1〜複数のコレクションへ割当（後述）。

## Shopify 管理画面での登録手順

各商品について同じ流れ:

```
管理画面 (https://sweet-atelier-demo.myshopify.com/admin)
  → 商品管理（左サイドバー）
    → 商品を追加

【入力項目】
タイトル → 上記の「商品名」
説明 → 上記の「説明文」を貼り付け
メディア → 該当する PNG をドラッグ＆ドロップ
  - 画像 ALT は別途設定可（編集ボタンから）
価格 → サイズ別の場合はバリエーションで設定
  - 単一サイズ商品はここに直接入力
原価（任意） → 入力不要
在庫管理
  - 「数量を追跡する」を ON
  - 数量に上記の在庫値を入力
配送
  - 「これは要配送商品です」を ON
  - 重量を入力
バリエーション
  - 複数サイズの場合 → 「オプションを追加」→ 名前: サイズ → サイズ別の値・価格・在庫を入力
商品の構成
  - 商品タイプ: ホールケーキ / タルト / 焼き菓子
  - ベンダー: Sweet Atelier
  - コレクション: 該当する handle を選択（or 後で割当）
  - タグ: 上記タグをカンマ区切りで
SEO
  - ページタイトル: 上記の「ページタイトル」
  - meta description: 説明文の冒頭 1 文を流用
ステータス
  - 「アクティブ」に
保存
```

## コレクションの登録手順

```
商品管理 → コレクション → コレクションを作成

【入力項目】
タイトル → コレクション設計表の「タイトル」
ハンドル → 同上の handle（自動入力されるが上記値に上書き）
説明 → 1〜2 行の説明文（任意、後で追加可）
コレクションタイプ → 手動
商品 → 該当商品を選択（または商品側のタグで自動）
画像 → Phase 2 で追加予定（今は空でOK）
```

## 進め方の推奨順

1. **コレクション 5 つを先に作成**（空でOK） — 商品登録時に割当できるように
2. **商品 1 から順に登録**（5商品）
3. **登録後に各商品の「コレクション」にチェック**で割当確認
4. **`shopify theme dev` でローカル確認** — `/products/strawberry-shortcake` 等で表示できるか

商品データはテーマファイルではなくストア側にあるため、`git` で管理されません。**このドキュメントが seed の唯一の記録**となります。
