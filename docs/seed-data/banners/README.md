## 設計方針

- **テキスト無し画像 6 枚 + テキスト焼込画像 4 枚** のハイブリッド方針
  - 通常運用は text-free + HTML overlay（編集性・SEO・多言語対応）
  - キャンペーン／ブランド紹介は焼込（デザインの完成度を優先）でケースを使い分け学習
- **ブランド方向性**: 季節と素材を映す、小さなケーキのアトリエ
  - 配色: オフホワイト `#FBF8F3` / カカオブラウン `#3D2B1F` / くすみピンク `#E8B4B8` / サンドベージュ `#D9C7A7`
  - タイポ（焼込時）: 見出しは明朝（Shippori Mincho B1 系）
